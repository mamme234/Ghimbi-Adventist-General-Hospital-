# Frontend pages

This directory contains static page entry points and page fragments used by the site. Pages are under frontend/pages/ and can be included into layouts using the client-side fragment loader already present in index.html.

Structure:
- frontend/pages/home - home page fragments
- frontend/pages/about - about pages
- frontend/pages/departments - department pages
- frontend/pages/patient - patient portal pages

Edit the HTML files and wire them with real data from the Render backend.
