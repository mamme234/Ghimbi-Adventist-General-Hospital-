# Ghimbi Adventist General Hospital — Frontend

This folder contains the static frontend for the hospital website. It is intentionally scaffolded as a professional, accessible, and responsive static site. Replace assets and wire the API endpoints as needed.

Deployment (Vercel): set project root to `frontend/` and deploy. If you keep the default vercel.json rewrite, API requests to `/api/*` will be proxied to your backend.
