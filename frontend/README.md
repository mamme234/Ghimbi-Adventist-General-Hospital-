# Frontend root README

This repository contains a modern, modular frontend skeleton for the hospital site. Place your real content in the frontend/pages and frontend/components folders. Replace assets in frontend/assets.

Features scaffolded:
- PWA manifest + service worker placeholder
- Component fragments in frontend/components
- Page fragments in frontend/pages
- CSS and JS skeletons under frontend/css and frontend/js

Development
- Use a simple static server during development: `npx serve .` or `python -m http.server`
